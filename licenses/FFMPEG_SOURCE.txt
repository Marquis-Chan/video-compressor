Both inputs are arm64 Mach-O executables with macOS 12.0 minimum load
commands. Their runtime version, configuration and license output are captured
again in each built application's licenses/FFMPEG_LICENSE_AND_SOURCE.txt.

The bundled binaries must report their applicable license with `ffmpeg -L`
and `ffprobe -L`. The build scripts append that output, the exact version and
configuration, and pre-signing input SHA256 values to
FFMPEG_LICENSE_AND_SOURCE.txt. BUILD_MANIFEST.txt records the authoritative
SHA256 of every final delivered file after platform signing.

Public distribution remains blocked until the exact original macOS binary
provider is known and all corresponding-source obligations have been reviewed.
The current record is intended only for the approved small-group internal
delivery.
